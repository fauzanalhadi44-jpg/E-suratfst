# E-suratfst
Sistem informasi berbasis web untuk pengajuan dan pemantauan surat mahasiswa di Administrasi FST UIN Imam Bonjol Padang. Mahasiswa mengajukan 7 jenis surat dan memantau statusnya, admin memeriksa dokumen, menyetujui atau menolak, lalu menerbitkan surat PDF bernomor otomatis. Dibangun dengan PHP dan MySQL.
